# IRent TN 🚗

Landing page for a luxury car rental service in Tunisia, built with a fully custom dark/gold visual identity and RTL Arabic support.

## Tech Stack

- **React 19** + **Vite** — app shell and build tooling
- **Tailwind CSS v4** — styling
- **React Router v7** — client-side routing
- **React Three Fiber / Drei / Three.js** — interactive 3D car model viewer
- **GSAP** — animations
- **Lucide React** + **React Icons** — iconography

## Features

- RTL Arabic UI with a custom gold/plate-inspired visual identity
- Responsive hero with a live booking widget (pickup location, date, car type)
- Interactive 3D car model viewer (WebGL, with fallback for unsupported devices)
- Full fleet catalog with filterable specs
- Custom navbar, footer, and card components built from scratch

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
